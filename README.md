# price-parser — парсер цен в Excel и CSV

Собирает товары с сайта-каталога и складывает их в готовую таблицу:
название, цена, рейтинг, наличие, ссылка на товар.

Демо-запуск на `books.toscrape.com` — учебном сайте, который специально
разрешён для парсинга: **60 товаров за 3.8 секунды**.

---

## Быстрый старт (Windows)

```powershell
# 1. Виртуальное окружение (один раз)
py -3.13 -m venv .venv

# 2. Зависимости (один раз)
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 3. Запуск: 3 страницы, пауза 0.5 сек между запросами
.\.venv\Scripts\python.exe parse_prices.py --pages 3 --delay 0.5
```

Результат появится в папке `output/`:

```
output/prices_2026-11-16_2156.csv
output/prices_2026-11-16_2156.xlsx
```

Параметры:

| Флаг | Значение по умолчанию | Что делает |
|---|---|---|
| `--start-url` | `https://books.toscrape.com/` | с какой страницы начать |
| `--pages` | `3` | сколько страниц обойти |
| `--delay` | `1.0` | пауза между запросами, сек |
| `--out` | `prices_<дата>` | имя файлов без расширения |

## Как подстроить под другой сайт

Вся привязка к разметке собрана в одном словаре `SELECTORS` в начале файла.

1. Открыть нужную страницу в браузере.
2. ПКМ по товару → «Посмотреть код».
3. Подставить классы карточки, названия, цены и ссылки.
4. Запустить с `--start-url` адресом этого каталога.

```python
SELECTORS = {
    "card": "article.product_pod",
    "title": "h3 a",
    "price": "p.price_color",
    "link": "h3 a",
    "rating": "p.star-rating",
    "availability": "p.instock.availability",
    "next_page": "li.next a",
}
```

Если у сайта нет кнопки «следующая страница», пагинация меняется на
подстановку номера страницы — это одна функция `next_page_url`.

## Что внутри

- `requests` — загрузка страниц, с таймаутом и 3 повторами при сбоях;
- `BeautifulSoup` — разбор HTML по CSS-селекторам;
- `openpyxl` — Excel с оформлением: жирная шапка, автофильтр, закреплённая строка, ссылки, числовой формат цены;
- CSV в `utf-8-sig` с разделителем `;` — открывается в русском Excel без танцев;
- пауза между запросами и нормальный User-Agent — чтобы не выглядеть DDoS-ботом.

## Ограничения, о которых честно

- **Сайт может блокировать.** Крупные маркетплейсы (Ozon, Wildberries, Авито)
  защищаются капчей и антиботом. Для них нужен браузерный парсинг или API.
- **`robots.txt` и условия сайта.** Собирать публичные цены обычно можно,
  но перед продажей решения конкретному клиенту — проверяй правила сайта.
- **Персональные данные не собираем.** ФИО, телефоны, почты — это уже
  закон о персональных данных, и за такое прилетает не от заказчика.
- **Цены меняются.** Это снимок на момент запуска, а не «живой» монитор.
  Для мониторинга нужен запуск по расписанию (Планировщик Windows / cron).

## Как это продавать

Три формулировки, которые уже готовы к размещению:

1. **«Соберу цены конкурентов в Excel»** — 2 500 ₽.
   Клиент: небольшой магазин, которому вручную лень смотреть 200 позиций.
2. **«Сделаю выгрузку товаров с сайта в таблицу»** — 1 500–3 000 ₽.
   Клиент: поставщик, которому нужен каталог для своего сайта.
3. **«Настрою ежедневный мониторинг цен»** — 1 500 ₽/мес.
   Клиент: тот, кому нужно не «один раз», а постоянно. Это повторные деньги.

Что важно говорить заказчику: «покажу на демо-данных, потом настрою под ваш сайт».
Демо у тебя уже есть — этот репозиторий.
